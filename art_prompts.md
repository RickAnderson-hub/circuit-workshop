# Circuit Workshop — Art Prompts

Reference for generating replacement illustrations for the game's current placeholder SVG shapes. Run these one at a time through an AI image generator (Midjourney, DALL-E, etc.), then trace the result to SVG (e.g. vectorizer.ai) so it stays crisp and swappable at any size.

Each prompt is self-contained and repeats the style guide, so they can be run independently in any order.

**Shared style guide** (baked into every prompt below): Day-of-the-Tentacle-style cartoon illustration, bold thick black outlines (~3-4px at final size), flat cel-shaded colors with no gradients or textures, simple and friendly enough for a 9-year-old, isolated on a plain white or transparent background, centered, no drop shadows.

**Existing color palette to match**: metal grey-blue `#c9d6e3`, pale head/panel `#e3ecf5`, warm cream `#f4e3c1`, wood/leather brown `#7a5a34` and `#c9b184`, accent yellow `#ffcc33`, accent red `#ff6b6b`, accent green `#27ae60`, outline black `#1a1a1a`.
